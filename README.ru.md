# HUMAC — запуск и загрузка на GitHub

Подробное описание проекта и ROS-интерфейса находится в [README.md](README.md).

## Запуск на Mac

Открой Terminal в папке `dashboard_app` и выполни:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
export SECRET_KEY="$(python -c 'import secrets; print(secrets.token_hex(32))')"
```

Если системный `python3` на Mac старее 3.10, создай окружение через `uv` вместо первой команды:

```bash
uv venv --python 3.13 --seed .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```


Нужен Python 3.10 или новее. Проверки выполнены на Python 3.13. Секретный ключ не нужно записывать в код или публиковать. Новый ключ отключает старые сессии. При запуске в новом Terminal переменную нужно задать снова; для постоянного использования храни один и тот же ключ в личных настройках окружения. Файл `.env` автоматически не загружается командой `python app.py`.

Если используешь старую локальную базу, аккаунты сохраняются. **Смени пароль, который раньше был записан в INFO.txt:**

```bash
python -m flask --app app:create_app reset-password Admin
```

Укажи точный логин своего аккаунта, если он отличается. Новый пароль вводится дважды скрытым вводом; длина — от 12 до 256 символов. Старые сессии этого аккаунта перестанут работать.

Для нового проекта без аккаунтов создай администратора:

```bash
python -m flask --app app:create_app create-user admin --admin
```

После этого запусти сайт:

```bash
python app.py
```

Открой <http://127.0.0.1:5000>. Регистрация через сайт отключена. Обычного оператора можно создать командой:

```bash
python -m flask --app app:create_app create-user operator
```

## Подключение робота

- Браузер должен видеть робота в доверенной локальной сети.
- На роботе нужны его рабочие ROS-ноды, rosbridge на порту `9090` и web_video_server на `8080`.
- Введи IP-адрес или имя робота и нажми CONNECT. Подключение отправляет нулевую скорость и RESET.
- После подключения явно сними программную остановку кнопкой RELEASE STOP.
- Для WASD и стрелок включи MANUAL OVERRIDE. Нажатие STOP или выключение ручного режима очищает нажатые клавиши и таймер.
- При смене вкладки или потере фокуса ручное управление отключается, а автономной миссии отправляется PAUSE, если связь работает.

Экранный E-STOP — программный запрос остановки. Его работу нельзя считать подтверждением физической остановки. Потерянное соединение не позволяет гарантировать доставку команды: нужен отдельный тайм-аут команд на роботе и физическая аварийная кнопка. Проверки на настоящем роботе в эту подготовку не входили.

Авторизация Flask защищает страницы, но не прямое подключение к rosbridge и камере. Эти сервисы нельзя открывать в публичный интернет. Проект настроен для локального HTTP; для публичного размещения нужна отдельная настройка сервера и защищённого шлюза к роботу.

## Проверки

```bash
python -m pip install -r requirements-dev.txt
python -m pytest -q
node --test tests/controls.test.cjs
```

Для последней команды нужен Node.js 22 или новее. Робот для тестов не требуется.

## Загрузка на GitHub

1. Создай пустой репозиторий `humac-robot-dashboard` на <https://github.com/new>. Сначала выбери Private. Не добавляй README, `.gitignore` и лицензию на сайте.
2. В Terminal перейди в папку `dashboard_app` и выполни:

   ```bash
   git init -b main
   git add .
   git status --short
   git diff --cached
   ```

3. Проверь список и изменения. Базы `harvester.db`, настоящего `.env`, паролей и папки `.venv` там быть не должно. `.gitignore` исключает их автоматически. `.env.example` можно загружать: настоящего ключа в нём нет.
4. Выполни команды, заменив `YOUR_USERNAME` на свой GitHub username:

   ```bash
   git commit -m "Initial commit: HUMAC robot dashboard"
   git remote add origin https://github.com/YOUR_USERNAME/humac-robot-dashboard.git
   git push -u origin main
   ```

5. Обнови страницу репозитория. Во вкладке Actions появится запуск автоматических тестов.

Для отправки кода нужна настроенная авторизация GitHub. Если HTTPS запрашивает пароль, используется токен доступа или менеджер учётных данных, а не обычный пароль GitHub. Для загрузки файла workflow токену также могут понадобиться права на workflows. Токен не нужно записывать в файлы проекта или URL репозитория.

GitHub хранит код. Сам сайт с Flask от одной загрузки не запускается; GitHub Pages для этого приложения не подходит.
